# Definition of Done

For meaningful engineering tasks:

- [ ] Requirement implemented.
- [ ] Scope matches the request.
- [ ] Existing architecture respected or intentional changes documented.
- [ ] No accidental public-contract changes.
- [ ] Tests added or updated where appropriate.
- [ ] Relevant tests pass.
- [ ] Static analysis / lint passes where available.
- [ ] Build passes where available.
- [ ] Database migration reviewed where applicable.
- [ ] Security review completed where applicable.
- [ ] Documentation updated where needed.
- [ ] Significant changes recorded in `AI_CHANGELOG.md`.
- [ ] Independent verifier has run.
- [ ] Verifier result is PASS or accepted PASS WITH CONDITIONS.
